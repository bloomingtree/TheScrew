## 1. 背景与目标

### 需求场景

让"螺丝钉"担任**运维人员**角色，具备以下能力：

1. **阅读运维文档**：读取本地的 Word/PDF 运维手册，理解文字和图片，回答问题时能引用文档内容和相关图片
2. **远程服务器管理**：通过 SSH/WinRM 远程连接 Linux 和 Windows Server
3. **执行运维操作**：运行命令、检查服务状态、查看日志、部署更新等
4. **安全可控**：危险操作需要确认，有完善的权限体系

### 运维文档问答示例


```markdown
5. **回滚预案**：执行变更前说明回滚方案
```

### 3.1 SSH 工具（Linux 服务器）

#### 工具定义

```typescript
{
  name: 'ssh',
  description: '通过 SSH 连接 Linux 服务器执行命令',
  parameters: {
    type: 'object',
    properties: {
      host: { type: 'string', description: '服务器地址' },
      port: { type: 'number', description: 'SSH 端口，默认 22' },
      user: { type: 'string', description: '用户名' },
      command: { type: 'string', description: '要执行的命令' },
      timeout: { type: 'number', description: '超时时间(ms)，默认 30000' },
      sudo: { type: 'boolean', description: '是否使用 sudo 执行' },
    },
    required: ['host', 'user', 'command']
  }
}
```

#### 技术实现

**方案 A：内嵌 Python + paramiko（推荐）**

```python
# 已有的嵌入 Python 3.8.10 + paramiko
import paramiko

def ssh_exec(host, port, user, command, key_path=None, password=None):
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    client.connect(host, port=port, username=user,
                   key_filename=key_path, password=password,
                   timeout=10)
    stdin, stdout, stderr = client.exec_command(command, timeout=30)
    return stdout.read().decode(), stderr.read().decode()
```

优点：
- 利用已有嵌入 Python
- paramiko 纯 Python，无需系统依赖
- 支持 SSH Key 和密码认证

**方案 B：Node.js + ssh2 库**

```typescript
import { Client } from 'ssh2';
// npm install ssh2
```

优点：
- 纯 Node.js 实现，不依赖 Python
- 与 Electron 主进程天然集成
- 支持流式输出

### 3.2 WinRM 工具（Windows Server 2012）

#### 背景

Windows Server 2012 **没有内置 OpenSSH Server**（OpenSSH 从 Win2019 才内置），因此需要 WinRM 进行远程操作。

#### WinRM 配置（在目标 Windows Server 上）

```powershell
# 1. 启用 WinRM
Enable-PSRemoting -Force

# 2. 配置 TrustedHosts（内网环境）
Set-Item WSMan:\localhost\Client\TrustedHosts "*" -Force

# 3. 允许非加密连接（内网可用）
winrm set winrm/config/service '@{AllowUnencrypted="true"}'

# 4. 验证
winrm enumerate winrm/config/listener
```

```typescript
{
  name: 'winrm',
  description: '通过 WinRM 连接 Windows 服务器执行命令',
  parameters: {
    type: 'object',
    properties: {
      host: { type: 'string', description: '服务器地址' },
      user: { type: 'string', description: '用户名（含域，如 admin@domain）' },
      command: { type: 'string', description: '要执行的 PowerShell 命令' },
      timeout: { type: 'number', description: '超时时间(ms)，默认 30000' },
      auth: {
        type: 'string',
        enum: ['basic', 'ntlm', 'kerberos'],
        description: '认证方式，默认 ntlm'
      },
    },
    required: ['host', 'user', 'command']
  }
}
```

#### 技术实现

**方案 A：内嵌 Python + pywinrm**

```python
import winrm

session = winrm.Session('192.168.1.50', auth=('admin', 'password'),
                         transport='ntlm')
result = session.run_ps('Get-Service | Where-Object {$_.Status -eq "Running"}')
```

依赖：`pip install pywinrm`，需要 `pywin32`

**方案 B：Node.js + node-winrm**

npm 包 `node-winrm` 或直接通过 HTTP 调用 WinRM SOAP 接口。

**方案 C：SSH 作为 Skill**

将 SSH 操作封装为 Skill（用户建议），而非纯工具：

```yaml
# .config/skills/ssh-ops/SKILL.md
---
name: ssh-ops
type: on-demand
keywords: [ssh, 远程, 连接, Linux, 服务器]
triggers:
  keywords: [ssh, 远程连接, Linux操作, 服务器操作]
---
```

优点：
- Skill 按需加载，不增加常驻工具数量
- 可包含丰富的系统提示和使用指南
- 可以和 devops Agent 配合使用
