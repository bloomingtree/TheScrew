## 1. 问题诊断

### 1.1 现象

在左侧文件树中点击 `.docx`、`.pptx`、`.pdf` 等 Office/二进制文档时，编辑器区域显示乱码（二进制内容被当作 UTF-8 文本渲染）。

### 1.2 影响范围

| 文件类型 | 当前行为 | 期望行为 |
|----------|---------|---------|
| `.docx` | Monaco 编辑器显示乱码 | 打开 Word 预览组件 |
| `.xlsx` | Monaco 编辑器显示乱码 | 打开 Excel 预览组件 |
| `.pptx` | Monaco 编辑器显示乱码 | 打开 PPT 预览组件 |
| `.pdf` | Monaco 编辑器显示乱码 | 打开 PDF 预览组件 |
| `.png/.jpg` | Monaco 编辑器显示乱码 | 打开图片预览组件 |
| `.txt/.ts` | Monaco 编辑器正常显示 | 保持不变（编辑器） |

## 2. 根因分析

### 2.1 完整调用链追踪

```
用户点击文件树中的文件
  │
  ├─ FileExplorer.tsx:159  handleFileClick(entry)
  │   │
  │   └─ 无条件打开 type: 'editor' 标签  ← 🔴 缺陷 A：无文件类型判断
  │       openTab({ type: 'editor', title, content: { filepath } })
  │
  ├─ tabStore.ts:100  openTab()
  │   │
  │   └─ 创建 'editor' 类型标签页
  │
  ├─ TabContent.tsx:109  case 'editor'
  │   │
  │   └─ 渲染 <EditorWrapper> 组件
  │
  ├─ TabContent.tsx:27  EditorWrapper.loadFile()
  │   │
  │   └─ fileEditor.readFile(filepath)
  │
  ├─ preload/index.ts  IPC → 'fileEditor:readFile'
  │
  └─ fileEditor.ts:38  🔴 缺陷 B：二进制文件以 UTF-8 读取
      const content = fs.readFileSync(filepath, 'utf-8');
          ↓
      .docx 二进制内容 → 乱码字符串
          ↓
      Monaco Editor 渲染乱码
```

### 2.2 三个缺陷

| 缺陷 | 位置 | 描述 |
|------|------|------|
| **A. 无类型路由** | `FileExplorer.tsx:164` | `handleFileClick` 对所有文件一律打开 `type: 'editor'`，不区分文本/二进制 |
| **B. 强制 UTF-8** | `fileEditor.ts:38` | `readFileSync(filepath, 'utf-8')` 将二进制文件作为文本读取 |
| **C. 无二进制防护** | `TabContent.tsx:16-72` | `EditorWrapper` 没有检测二进制文件并拒绝渲染 |

### 2.3 讽刺之处

**正确的预览系统已经存在但未被使用：**

```
✅ 已有的预览组件：
  WordPreview.tsx  → 调用 word:preview IPC → mammoth 转 HTML
  ExcelPreview.tsx → 调用 file:preview IPC → xlsx 库解析
  PPTXPreview.tsx  → 调用 pptx:preview IPC → pizzip 解析
  PDFPreview.tsx   → 调用 pdf:preview IPC  → pdf-parse 提取
  ImagePreview.tsx → 调用 file:preview IPC → base64 渲染

❌ 问题：FileExplorer 不走这条路径，而是走 fileEditor → Monaco 编辑器
```

旧版侧边栏（`Sidebar/index.tsx:254`）使用 `type: 'preview'`，可以正确路由。但新版 `FileExplorer` 组件改用了 `type: 'editor'`，破坏了该功能。

## 3. 解决方案

### 3.1 核心思路：文件类型智能路由

在 `FileExplorer.handleFileClick` 中根据文件扩展名判断类型，分别路由到编辑器或预览：

```
文件点击
  │
  ├─ 文本/代码文件 (.ts, .js, .py, .md, .json, ...)
  │   → type: 'editor'  → Monaco 编辑器
  │
  └─ Office/二进制文件 (.docx, .xlsx, .pptx, .pdf, .png, ...)
      → type: 'preview' → PreviewTab → 具体预览组件
```

### 3.2 修改方案

#### 修改 1：`FileExplorer.tsx` — 添加文件类型路由

```typescript
// 判断文件应打开为编辑器还是预览
function getFileOpenMode(filename: string): 'editor' | 'preview' {
  const ext = filename.split('.').pop()?.toLowerCase() || '';

  // 预览模式：Office 文档、图片、PDF
  const previewExtensions = new Set([
    'docx', 'xlsx', 'xls', 'pptx', 'pdf',
    'png', 'jpg', 'jpeg', 'gif', 'bmp', 'webp', 'svg', 'ico',
  ]);

  return previewExtensions.has(ext) ? 'preview' : 'editor';
}

// 修改 handleFileClick
const handleFileClick = async (entry: FileEntry) => {
  if (entry.type === 'directory') {
    toggleExpand(entry);
  } else {
    const openMode = getFileOpenMode(entry.name);
    openTab({
      type: openMode,          // ← 根据类型选择 'editor' 或 'preview'
      title: entry.name,
      content: { filepath: entry.path },
    });

    if (onFileClick) {
      onFileClick(entry.path);
    }
  }
};
```

#### 修改 2：`fileEditor.ts` — 添加二进制文件防护

```typescript
ipcMain.handle('fileEditor:readFile', async (_event, filepath: string) => {
  try {
    if (!fs.existsSync(filepath)) {
      return { success: false, error: '文件不存在' };
    }

    // 🔒 二进制文件防护：检测并拒绝
    const ext = path.extname(filepath).toLowerCase();
    const binaryExtensions = new Set([
      '.docx', '.xlsx', '.xls', '.pptx', '.ppt',
      '.pdf', '.png', '.jpg', '.jpeg', '.gif', '.bmp', '.webp', '.svg',
      '.zip', '.rar', '.7z', '.exe', '.dll', '.so', '.dylib',
    ]);

    if (binaryExtensions.has(ext)) {
      return {
        success: false,
        error: `二进制文件（${ext}）不支持文本编辑，请使用预览功能查看`,
      };
    }

    const content = fs.readFileSync(filepath, 'utf-8');
    return { success: true, content };
  } catch (error: any) {
    return { success: false, error: error.message };
  }
});
```

#### 修改 3：`EditorWrapper` — 友好的二进制文件提示

```typescript
// TabContent.tsx EditorWrapper 中增加提示
const loadFile = async () => {
  try {
    const result = await window.electronAPI.fileEditor.readFile(filePath);
    if (result.success) {
      setContent(result.content);
      openFile(filePath, result.content, false);
    } else {
      // 如果是二进制文件被拒绝，显示友好提示
      if (result.error?.includes('二进制文件')) {
        setContent(`// ${result.error}\n// 请在文件树中右键选择"预览"查看此文件`);
      } else {
        setContent(`// 无法读取文件: ${result.error || '未知错误'}`);
      }
    }
  } catch (error) {
    setContent(`// 读取文件时出错: ${error}`);
  }
};
```

## 4. 预览库选型对比

### 4.1 Word (.docx) 预览

| 方案 | 库 | 保真度 | 大小 | 离线 | 推荐 |
|------|------|--------|------|------|------|
| **A. mammoth** | `mammoth` | 中（语义 HTML） | ~200KB | ✅ | 当前方案 |
| **B. docx-preview** | `docx-preview` | 高（保留排版/样式/图片） | ~500KB | ✅ | **推荐升级** |
| C. LibreOffice headless | 系统命令 | 最高 | 需安装 | ✅ | 重度需求 |
| D. Google Docs Viewer | 在线服务 | 高 | 0 | ❌ | 不适合离线 |

**推荐方案：升级到 `docx-preview`**

`docx-preview` 是目前最流行的开源 DOCX 渲染库，在 Electron 的 Chromium 环境中运行良好：

```typescript
// 使用示例
import { renderAsync } from 'docx-preview';

// 在 React 组件中
const containerRef = useRef<HTMLDivElement>(null);

useEffect(() => {
  const loadDocx = async () => {
    const response = await fetch(filePath);  // 或从 IPC 获取 ArrayBuffer
    const blob = await response.blob();
    if (containerRef.current) {
      await renderAsync(blob, containerRef.current, undefined, {
        className: 'docx-preview-wrapper',
        inWrapper: true,
        ignoreWidth: false,
        ignoreHeight: false,
      });
    }
  };
  loadDocx();
}, [filePath]);
```

**mammoth vs docx-preview 对比：**

| 特性 | mammoth | docx-preview |
|------|---------|-------------|
| 标题/段落 | ✅ | ✅ |
| 表格 | ✅ | ✅ |
| 图片（嵌入） | ✅ | ✅ |
| **字体/字号** | ❌ 转为语义 HTML | ✅ 保留原样式 |
| **页面布局** | ❌ 线性流式 | ✅ 分页渲染 |
| **页眉页脚** | ❌ | ✅ |
| **脚注/尾注** | 部分 | ✅ |
| **批注** | ❌ | ✅ |

### 4.2 Excel (.xlsx) 预览

当前使用 `xlsx` 库，已能满足需求。如需更高保真度，可考虑：

| 方案 | 说明 |
|------|------|
| 当前（xlsx） | ✅ 已实现，功能完整 |
| ` Luckysheet` | 在线电子表格，支持公式计算 |
| `Handsontable` | 商业级数据网格 |

**结论：保持当前方案。**

### 4.3 PPT (.pptx) 预览

| 方案 | 库 | 保真度 | 说明 |
|------|------|--------|------|
| **A. 文本提取** | pizzip + XML 解析 | 低 | **当前方案**，仅提取文字 |
| **B. pptx-browser** | `pptx-browser` | 中 | 渲染到 Canvas，零依赖 |
| **C. PptxViewJS** | `pptxviewjs` | 中-高 | Canvas 渲染，保留布局 |
| **D. LibreOffice→PDF** | 系统命令 | 高 | 需安装 LibreOffice |

**推荐方案：短期保持文本提取，中期引入 `pptx-browser`**

`pptx-browser` 将 PPTX 幻灯片渲染到 HTML Canvas，保留基本布局和文本样式，适合预览场景。

```bash
npm install pptx-browser
```

### 4.4 PDF 预览

| 方案 | 库 | 保真度 | 说明 |
|------|------|--------|------|
| **A. 文本提取** | `pdf-parse` | 低 | **当前方案**，仅提取文本 |
| **B. react-pdf** | `react-pdf` + `pdfjs-dist` | **高** | 渲染原始页面，支持缩放/搜索 |
| **C. pdfjs-dist 直接使用** | `pdfjs-dist` | 高 | 更底层，控制更精细 |

**推荐方案：升级到 `react-pdf`**

`react-pdf` 是 `pdfjs-dist` 最流行的 React 封装，提供页面级渲染，支持：
- 原始页面渲染（非文本提取）
- 缩放、翻页、搜索
- 文本选择
- 缩略图导航

```bash
npm install react-pdf pdfjs-dist
```

```typescript
// React-PDF 使用示例
import { Document, Page } from 'react-pdf';
import 'react-pdf/dist/Page/AnnotationLayer.css';
import 'react-pdf/dist/Page/TextLayer.css';

// 设置 worker（Electron 离线支持）
import { pdfjs } from 'react-pdf';
pdfjs.GlobalWorkerOptions.workerSrc = new URL(
  'pdfjs-dist/build/pdf.worker.min.mjs',
  import.meta.url
).toString();

const PDFPreview = ({ filepath }) => {
  const [numPages, setNumPages] = useState(0);
  const [pageNumber, setPageNumber] = useState(1);

  return (
    <Document
      file={filepath}
      onLoadSuccess={({ numPages }) => setNumPages(numPages)}
    >
      <Page pageNumber={pageNumber} width={600} />
    </Document>
  );
};
```

### 5.3 文件类型路由配置

集中管理的文件类型配置，避免在多处重复判断：

```typescript
// src/utils/fileTypeRouter.ts（建议新增）

export type FileOpenMode = 'editor' | 'preview';

// 预览模式的文件扩展名
const PREVIEW_EXTENSIONS = new Set([
  // Office 文档
  'docx', 'xlsx', 'xls', 'pptx', 'ppt',
  // PDF
  'pdf',
  // 图片
  'png', 'jpg', 'jpeg', 'gif', 'bmp', 'webp', 'svg', 'ico',
]);

// 二进制文件扩展名（不允许在编辑器中打开）
const BINARY_EXTENSIONS = new Set([
  ...PREVIEW_EXTENSIONS,
  'zip', 'rar', '7z', 'tar', 'gz',
  'exe', 'dll', 'so', 'dylib',
  'mp3', 'mp4', 'avi', 'mov', 'wav',
  'woff', 'woff2', 'ttf', 'eot',
]);

export function getFileOpenMode(filename: string): FileOpenMode {
  const ext = filename.split('.').pop()?.toLowerCase() || '';
  return PREVIEW_EXTENSIONS.has(ext) ? 'preview' : 'editor';
}

export function isBinaryFile(filename: string): boolean {
  const ext = filename.split('.').pop()?.toLowerCase() || '';
  return BINARY_EXTENSIONS.has(ext);
}
```
